# LLM Mesh - ML/AI Intelligence Layer

This directory contains the ML/AI components that enhance commit-relay with intelligent routing, prediction, and context-aware agents.

## Quick Start

See `/docs/ML-AI-ARCHITECTURE.md` for complete architecture and implementation details.

## Structure

```
llm-mesh/
├── models/              # Trained models
├── training-data/       # Training datasets  
├── vectors/             # Vector stores for RAG
├── scripts/             # Training/inference scripts
└── lib/                 # Reusable ML libraries
```
