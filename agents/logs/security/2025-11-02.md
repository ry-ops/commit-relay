### Incident Overview

**Discovery**: CodeRabbit AI comprehensive security scan
**Issue**: Security regression in n8n-mcp-server
**Root Cause**: Week 2 infrastructure refactoring (commit cf793c6) removed Week 1 security fixes (commit c428f78)
**Severity**: 🔴 CRITICAL
**Priority**: IMMEDIATE

### Vulnerabilities Detected

1. **CVE-PATH-001: Path Traversal/Injection in API Parameters**
   - **Severity**: CRITICAL
   - **Impact**: Unauthorized API endpoint access, data leakage, access control bypass
   - **Affected**: 8 methods (_get_workflow, _update_workflow, _delete_workflow, _activate_workflow, _deactivate_workflow, _execute_workflow, _get_execution, _delete_execution)
   - **Attack Vector**: `workflow_id="../../../admin/users"`

2. **CVE-INFO-001: Information Disclosure via Verbose Error Messages**
   - **Severity**: CRITICAL
   - **Impact**: Exposure of internal implementation details, stack traces, file paths
   - **Affected**: Error handling in _make_request method
   - **Attack Vector**: Intentional error triggering to gather system information

3. **CVE-2025-53365 & CVE-2025-53366: Outdated MCP Dependency**
   - **Severity**: CRITICAL
   - **Impact**: Remote code execution, authentication bypass, data corruption
   - **Affected**: MCP SDK version 1.1.2 (vulnerable)
   - **Fix Required**: Update to >=1.9.4
